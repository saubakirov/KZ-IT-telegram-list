unchanged typed classifier, a closed canonical preview, physically separate owner authority and
execution records, and complete location-neutral command copies. Phase A receives synthetic
fixtures plus eight precommitted calibration cases. The twenty holdout cases and their raw source

## 4. Scope, Sequence, and Budget

1. Establish deterministic source parsing, candidate grouping, observation, preview, authority,
   and apply-state contracts with synthetic fixtures.
2. Preserve the existing identity/type classifier while extracting only the minimum immutable
   fetch/retry seam needed by candidate intake.
3. Make all three `kz-*` command bodies complete, location-neutral, synchronized, and testable in
   both runtimes.
4. Use only the committed eight-case calibration input for real candidate evidence; never add a
   production row in this phase.
5. Obtain fresh read-only Claude and Codex routing evidence at the exact implementation SHA.
6. Submit ONB, EV, RF, and the unchanged implementation/evidence base to formal review.

Expected implementation budget: at most 13 implementation paths, at most 8 new implementation
files, at most 2500 insertion-plus-deletion lines. Trace and evidence files are additional. Any
shared observation-module refactor, third command source, dependency for generic JCS, GUI, service,
or new catalog row exceeds the phase and requires Coordinator re-planning.
